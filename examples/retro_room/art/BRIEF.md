# Art brief

- **What:** a walkable test room for KILN's retro looks (#362): nine objects on pedestals in a 3x3 grid.
- **Camera:** first person, walking all the way round each pedestal.
- **Style:** `retro_st` (Atari ST colour); the room also switches to `retro_cga` and `retro_mono`, which quantise
  the same models (no per-look recolouring yet: this tests the simple method).
- **Models** (real-world sizes; the room scales each to the same size on its pedestal): monstera, chair, painting on
  an easel, car, desk lamp, globe on a stand, teapot, acoustic guitar, 1980s home computer with monitor (no brand).
- **Colours:** only the palette's 16 colours (`palettes/main.pal.yaml`, Atari ST).
